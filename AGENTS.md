NBSP: No Bull-Shit Print

Printer utility desktop app. It was built for my personal Epson L3210, and works with other CUPS printers.

Features:

- Side by side
- Double sided
- Reversed order (but make it the expected order by default where the first page is on the top of the printed papers)
- Margins
- Custom paper sizes/presets
- Adjustable and customizable page count
- Booklet
- Color, quality, etc
- Preview
- Scan to pdf
- Pages editor (pdf, scan, add page, rearange, rotate, etc)
- Other features you may find useful

Design and UI:

- Minimal, functional, intuitive. (No BS)
- Always use shadcn-svelte components when applicable.
- Minimal meta commentary or explanation, good design should explain itself. But if necessary try to progressively explain the info.

Code:

- Use `cn` for conditional class names
- Prioritize performance.
